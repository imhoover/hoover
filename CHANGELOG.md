# Changelog

All notable changes to Hoover will be documented in this file.

The project follows a practical release-note style focused on maintainer-facing changes.

## v0.1.0 — Initial public release

Initial public release of Hoover, an open-source maintainer workflow toolkit for turning long issue reports, PR notes, release updates, and contributor messages into clear maintainer briefs.

### Added

- Deterministic maintainer brief generation.
- Markdown and plain-text input support.
- Local command-line workflow.
- Problem statement detection.
- Reproduction signal detection.
- Risk signal detection.
- Suggested next-action output.
- Reviewable Markdown rendering.
- Tests for initial parser behavior.
- Examples for maintainer workflows.
- MIT license.
- Contributing guide.
- Code of conduct.
- Security policy.
- Roadmap for JSON output, issue-template integration, release-note briefs, multilingual support, and optional AI-assisted workflows.

### Project status

Hoover is early-stage. This release is intended to provide a small, understandable base for future maintainer-focused workflows.

### Notes

The current version is local-first and does not require external services.
